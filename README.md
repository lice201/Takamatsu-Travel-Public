## Local development

```bash
npm install
npm run dev
```

GitHub Pages용 정적 결과물은 `npm run build:pages`로 `dist/client`에 생성됩니다.

이 공개 저장소가 앞으로 여행기 개발과 배포의 기본 저장소입니다. 원본 비공개 저장소의 Git 기록은 포함하지 않습니다.
