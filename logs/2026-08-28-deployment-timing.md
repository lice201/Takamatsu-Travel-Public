# 2026-08-28 여행기 사이트 공개 배포 시점

- 현재 `/travel-log`는 구조, 실제 동선, 사진 확장, FOOD 섹션까지 구현된 상태.
- 아직 실제 여행 사진, 음식 사진, 메뉴, 짧은 후기 등 핵심 콘텐츠가 placeholder/TODO 상태이므로 공개 배포는 보류하는 것이 적절함.
- 권장 순서:
  1. 실제 사진을 `trip-data.ts`에 연결
  2. Honetsukidori / Sushiro 메뉴 및 1~2줄 후기 입력
  3. Hero / Epilogue 실제 사진 교체
  4. 모바일·데스크톱 최종 시각 점검
  5. lint/build/test 재검증
  6. Sites 공개 배포
- 즉, 현재 main 반영은 개발/콘텐츠 입력 단계이고, 공개 배포는 실제 콘텐츠 입력 완료 후 최종 QA 직후 진행.
