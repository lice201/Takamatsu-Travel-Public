### 4. 3차 개선 요구사항 — 쇼도시마 불가 시 Plan B

기상 악화 상황을 두 단계로 분리한다.

#### Plan B-1: 페리만 결항, 다카마쓰 시내 이동은 정상

DAY 3을 “다카마쓰 실내 문화·상점가 데이”로 교체한다.

- 09:30 고토덴 또는 도보 이동 상태 확인
- 10:00 고토히라/섬 일정과 겹치지 않는 시내 실내 명소 우선
- 고정 후보: 다카마쓰시 미술관
  - 2026-08-26 수요일 운영 대상
  - 09:30–17:00
  - 여행 기간 중 특별전·컬렉션전 개최
- 점심: 중앙상점가의 우동 또는 카페
- 오후: 마루가메마치 그린 → 가와라마치 FLAG → 미쓰코시 등 실내·아케이드 쇼핑
- 남는 시간: 와산본·우동·야돈 기념품 구매, 숙소에서 휴식
- 야외 동선은 최소화하고 숙소에서 도보권인 장소를 우선한다.

#### Plan B-2: 태풍 접근·폭우·강풍으로 시내 교통도 불안정

- 관광 일정을 강행하지 않고 숙소 또는 가장 가까운 안전한 실내 공간에 머문다.
- 일본 기상청, 다카마쓰시 방재 정보, 항공사, 공항 리무진, 페리사의 공지를 확인한다.
- 하천·해안·항구·지하 통로와 전망대 방문을 피한다.
- 귀국편 영향 가능성이 있으면 항공사 변경/결항 안내와 공항 접근 가능 여부를 먼저 확인한다.
- 쿠폰 절약액보다 안전을 우선한다는 문장을 눈에 띄게 표시한다.

DAY 3 카드에는 “전날 18:00 1차 판단 → 당일 06:00 최종 판단” 체크포인트를 추가하되, 운항사의 발표 시각이 다를 수 있으므로 고정 시각은 권장 확인 시각으로만 쓴다.

### 5. 4차 개선 요구사항 — 렌터카 없는 쇼도시마 vs 나오시마 재비교

기존의 “쇼도시마는 4명이면 렌터카 추천, DAY 3 확정” 문구를 삭제하고, 대중교통만 이용한다는 전제에서 다시 평가한다.

| 비교 항목 | 쇼도시마 | 나오시마 |
|---|---|---|
| 섬 규모/동선 | 크고 관광지가 넓게 분산 | 상대적으로 작고 주요 구역이 선형으로 연결 |
| 차 없는 이동 | 올리브버스 시간표에 일정 전체를 맞춰야 함 | 미야노우라–혼무라–츠츠지소 마을버스 + 미술관 무료 셔틀 |
| 대중교통 비용 | 1일권 성인 ¥1,600 | 마을버스 성인 1회 ¥100, 미술관 셔틀 무료 |
| 일정 난이도 | 높음. 핵심 2곳 권장 | 중간. 환승은 있으나 공식 당일 코스가 있음 |
| 4인 장점 | 페리 쿠폰으로 4인 왕복 교통비 절감 | 렌터카 없이도 이동 구조가 비교적 명확 |
| 약점 | 배차가 적고 엔젤로드·올리브공원·간장마을 3곳을 모두 넣기 빠듯함 | 페리 쿠폰 미적용, 미술관 입장료와 시간 지정 예약 필요 |
| 날씨 영향 | 야외 명소 비중이 높고 버스 대기 부담 | 실내 미술관 비중이 높지만 야외 이동과 혼잡은 존재 |
| 추천 대상 | 올리브·바다·소면·엔젤로드가 최우선 | 현대미술·건축이 최우선, 차 없이 효율을 중시 |
| 종합 판단 | 쿠폰 활용을 원하면 “핵심 2곳 축소형”으로 가능 | 렌터카 불가 조건만 보면 이동 현실성은 더 높음 |

쇼도시마 유지 시 웹페이지의 DAY 3은 다음 원칙으로 수정한다.

- 07:20 다카마쓰 출발 → 08:20 도노쇼항 도착
- 도착 후 올리브버스 1일권 구매
- 간조 시간이 맞으면 엔젤로드 + 올리브공원 2곳을 기본 축으로 구성
- 간장마을은 당일 버스 연결이 여유 있을 때만 선택하는 옵션으로 내린다.
- 각 구간에 실제 노선명·정류장·다음 버스 시각·놓쳤을 때 대체편을 표시한다.
- 16:30 도노쇼 출발편을 목표로 하되, 최소 한 편의 복귀 버퍼를 시각적으로 표시한다.
- 노선버스 관광은 가능하지만 “무리 없이 가능”이라는 표현은 쓰지 않는다.

나오시마 선택 시에는 08:12 다카마쓰 출발–09:02 미야노우라 도착 후 마을버스와 무료 셔틀을 이용하고, 지중미술관 등은 사전 시간 지정 예약을 전제로 한다. 렌터카 불가 조건에서는 나오시마를 이동 편의 우세, 쇼도시마를 쿠폰·자연 체험 우세로 표현한다.

### 6. 5차 개선 요구사항 — 섬을 모두 포기하는 Plan C

쇼도시마와 나오시마 중 하나를 고르는 구조 외에, 두 섬을 모두 선택하지 않고 근교 도시로 이동하는 독립적인 DAY 3 대안을 추가한다.

#### Plan C 기본안: 구라시키 미관지구 철도 당일치기

선정 이유:

- 다카마쓰역에서 JR 쾌속 마린라이너로 오카야마역까지 이동한 뒤, JR 산요본선으로 구라시키역에 접근 가능
- 렌터카와 페리를 전혀 이용하지 않음
- 구라시키역에서 미관지구까지 도보 약 15분이며, 미관지구·오하라미술관·아이비 스퀘어·카페와 상점이 밀집해 있음
- 2026-08-26 수요일에도 오하라미술관은 8월 무휴 일정에 해당하며, 한여름에 실내 관람을 섞을 수 있음

권장 DAY 3 구조:

1. 오전 08:00 전후 다카마쓰역 출발
2. 오카야마역 환승 후 오전 10:00 전후 구라시키역 도착
3. 구라시키 미관지구 산책
4. 현지 점심
5. 오하라미술관 관람
6. 아이비 스퀘어, 구라시키 데님·공예품 상점, 카페 중 취향에 맞춰 선택
7. 17:00 전후 구라시키 출발, 저녁에 다카마쓰 복귀

웹페이지 구현 원칙:

- 위 시각은 일정 틀만 보여주는 예시이며 2026-08-26 공식 열차 시각을 다시 확인해 확정한다.
- 각 열차의 출발·도착 시각, 환승역, 환승 여유, 왕복 예상 교통비를 표시한다.
- 구라시키에서 모든 장소를 억지로 넣지 않고 미관지구+오하라미술관을 핵심으로 둔다.
- 쇼도시마 페리 쿠폰을 사용하지 못한다는 점과 추가 철도비·미술관 입장료가 든다는 점을 명확히 표시한다.
- 8월 폭염을 고려해 야외 산책은 오전과 늦은 오후에 배치하고, 12:00~15:00에는 식사·미술관·카페 등 실내 비중을 높인다.
- 섬 비교 영역을 쇼도시마·나오시마·구라시키 3안 비교로 확장한다.

안전 구분:

- Plan C는 날씨가 정상이고 섬 대신 육상 도시 여행을 선택할 때 사용하는 독립 대안이다.
- 다카마쓰–오카야마 열차는 세토대교를 통과하므로 강풍·태풍 때 운휴 또는 지연될 수 있다.
- 따라서 페리 결항 원인이 태풍·강풍이라면 Plan C로 자동 전환하지 않는다.
- 재해 시에는 JR 운행 상태를 별도로 확인하며, 시내 이동도 위험하면 기존 Plan B-2의 숙소 대기 원칙을 유지한다.

- C안: 구라시키 — 섬과 페리를 모두 포기하고 철도·도보 중심의 역사도시 당일치기
- 재해 대안은 A/B/C 선택안과 별개로 유지하며, 운행 안전이 확인된 교통수단만 이용한다.


### 7. Plan C 후보 재검토 — 고베 vs 구라시키

사용자 요청에 따라 기존 프롬프트에는 아직 반영하지 않고, 2026-08-26 수요일·다카마쓰 출발·4인·렌터카 없음 조건에서 두 도시의 적절성만 우선 평가했다.

#### 교통 및 비용 비교

| 항목 | 구라시키 | 고베 |
|---|---|---|
| 권장 접근 | 마린라이너로 오카야마, 산요본선 환승 | 고속버스로 다카마쓰역–산노미야 직행 |
| 편도 이동 | 약 1시간 15~35분 | 약 2시간 50분 |
| 왕복 기본 교통비 | 1인 ¥3,680 / 4인 ¥14,720 | 1인 ¥7,700 / 4인 ¥30,800 |
| 환승·예약 | 오카야마 1회 환승, 자유석은 사전예약 불필요 | 환승 없음, 좌석 사전예약 권장 |
| 현지 이동 | 미관지구까지 도보 약 15분, 핵심지가 밀집 | 산노미야·기타노·난킨마치·항구 구간에 도보와 시티루프 조합 |
| 일정 여유 | 이동 부담이 작고 복귀편 선택 폭이 큼 | 하루 일정은 가능하지만 왕복 약 5시간 40분을 버스에서 보냄 |

고베 고속버스의 현실적인 예시는 고마쓰역이 아닌 다카마쓰역 고속BT 기준 06:55 출발→09:45 산노미야 도착, 19:05 산노미야 출발→21:57 다카마쓰 복귀이다. 고베 체류 약 9시간 20분으로 공식 7시간 초행자 코스는 소화 가능하나, 아침·저녁 이동 피로가 크다. 철도·신칸센을 이용하면 더 빠를 수 있으나 비용과 환승 부담이 커져 Plan C의 장점이 약해진다.

#### 관광 성격 비교

- 구라시키: 미관지구, 오하라미술관, 아이비 스퀘어, 공예품·카페가 좁은 범위에 모인 역사·미술 중심 일정이다. 2026년 8월 오하라미술관은 무휴이고 09:00~17:00 운영 예정이다. 일정의 완성도와 이동 효율이 높지만, 도시 규모와 쇼핑·먹거리 선택 폭은 고베보다 작고 폭염 시 야외 거리 산책 비중이 부담이 될 수 있다.
- 고베: 기타노 이진칸, 난킨마치, 메리켄파크, 하버랜드 등 볼거리·식사·쇼핑 선택 폭이 넓고, 하버랜드 같은 대형 실내 시설을 넣어 폭염 대응이 쉽다. 반면 주요 구역이 구라시키보다 넓게 퍼져 있고, 현지에서도 시티루프나 추가 도보가 필요하다. 고베 공식 초행자 모델 코스 자체가 약 7시간이다.

#### 잠정 결론

- 고베는 당일치기 자체가 무리한 선택은 아니며, “먹거리·쇼핑·항구 야경까지 포함한 대도시 여행”을 최우선으로 두면 선택 가치가 있다.
- 그러나 섬을 포기했을 때 이용하는 간단하고 안정적인 근교 대안이라는 Plan C의 목적에는 구라시키가 더 잘 맞는다.
- 4인 기준 고베의 왕복 교통비는 구라시키보다 약 ¥16,080 높고, 총 이동시간도 약 2시간 40분 이상 늘어난다.
- 따라서 현재 1순위는 구라시키를 유지한다. 고베는 그룹이 고베 자체를 강하게 원하거나, 이동 피로와 추가 비용을 감수하고 도시형 관광을 선호할 때만 대체 후보로 둔다.
- 이 결론은 아직 실행 프롬프트와 웹페이지에 반영하지 않는다. 사용자가 최종 도시를 선택한 뒤 해당 도시의 정확한 시간표·동선·식사·비용을 상세 계획으로 작성해 프롬프트에 반영한다.

### 10. 쇼도시마·나오시마 페리 소요시간 표기 추가

사용자 요청에 따라 DAY 3 선택안 비교표와 각 섬 일정 카드에 페리 소요시간을 함께 표시하도록 프롬프트를 보완한다.

- 나오시마 출항편: 다카마쓰항 → 미야노우라항 일반 페리, 약 50분
- 나오시마 귀환편: 미야노우라항 → 다카마쓰항 일반 페리, 약 60분
- 나오시마 일반 페리 왕복 승선시간: 약 110분
- 나오시마 고속선은 편도 약 30분이지만 일반 페리와 선종·운임·운항편이 다르므로 별도 보조 정보로 구분하며, 비교표의 기본값은 일반 페리로 통일한다.

프롬프트 반영 원칙:

- 승선시간과 항구 대기·발권·승선 마감 시간을 구분한다. 소요시간에 대기시간을 포함한 것처럼 표현하지 않는다.
- 나오시마 고속선을 대체편으로 표시할 경우 일반 페리와 운임, 수송 조건, 시간표가 다르다는 점을 함께 안내한다.
- 소요시간은 현재 공식 시간표 기준값으로 표시하고, 2026-08-26 실제 운항편은 여행 직전에 다시 확인한다.

### 11. 야간 콘텐츠·야돈 스탬프·일정 사진·페리 시간 보완 프롬프트

사용자가 기존 웹페이지에 다음 네 가지 요구사항을 함께 반영하는 추가 수정용 프롬프트를 요청했다.

1. 날씨 영역에 밤 평균 기온을 추가하고, 이자카야·현지 슈퍼마켓 쇼핑·야간 산책 등 밤에 할 수 있는 콘텐츠를 실제 사진과 함께 강화한다.
   - 2026년 여행일의 확정 예보처럼 표현하지 않고 공식 기후자료 또는 신뢰할 수 있는 자료의 평년값/현재 확인값으로 표시한다.
   - 야간 영업시간, 휴무일과 안전한 귀환 동선은 공식 출처에서 확인하며 검증되지 않은 장소·가격·혜택을 만들지 않는다.
2. 이동 부담이 큰 야돈공원은 일정, 지도, 추천 카드와 사진 영역에서 제거한다.
   - 대신 숙소와 기존 일정 동선에서 접근 가능한 공식 야돈 스탬프 설치 지점만 확인해 현실적인 미니 투어로 구성한다.
   - 각 지점의 장소명, 주소, 가까운 역·정류장, 기존 일정과 연결되는 날짜, 예상 추가 이동, 스탬프 이용 가능시간과 인증 방식, 공식 출처를 표시한다.
   - 전 지점 완주를 강요하지 않고 2~4곳 정도의 접근 가능한 핵심 코스와 추가 선택 지점을 구분한다.
3. ‘사진으로 걸어보는 일정’은 공통 일정 사진과 플랜별 고유 관광지 사진을 분리한다.
   - DAY 1·2·4 등 모든 플랜에 공통인 일정은 공통 사진을 한 번만 사용한다.
   - DAY 3의 쇼도시마·나오시마·구라시키 Plan C는 각 플랜 카드 또는 탭 안에 해당 관광지의 실제 사진만 배치한다.
   - 다른 플랜의 관광지 사진을 재사용하거나 잘못 연결하지 않으며, 사진 캡션에 장소명과 플랜명을 표시한다.
4. 각 페리의 방향별 편도 소요시간과 왕복 총 승선시간을 비교표와 일정 카드에 표시한다.
   - 쇼도시마: 다카마쓰항↔도노쇼항 일반 페리 편도 약 60분, 왕복 약 120분.

   - 구라시키 Plan C는 ‘페리 없음·JR 이용’으로 표시한다.
   - 승선시간에는 발권, 대기와 승선 준비시간이 포함되지 않는다고 안내하고 2026-08-26 실제 운항편은 여행 직전 공식 시간표에서 재확인한다.

### 14. 추가 수정 프롬프트의 도구 사용량 최소화

작업일: 2026-08-03

직전의 야간 콘텐츠·야돈 스탬프·사진 구조·페리 시간 수정 프롬프트를 기능 요구사항은 유지하면서 도구 사용량을 줄이는 방향으로 재작성했다.

사용량 절감 원칙:

- 저장소 전체를 반복 탐색하지 않고 관련 파일만 읽는다.
- 전체 HTML·DOM·접근성 트리·브라우저 문서 전문은 출력하지 않는다.
- 기존에 검증한 페리 시간, 여행 구조와 디자인 정보는 재검색하지 않는다.
- 웹 검색은 반드시 필요한 미확인 정보에만 사용하고 항목당 공식 출처 1개를 우선한다.
- 서브에이전트를 사용하지 않는다.
- 정상 의존성이 있으면 `npm install`을 생략하고, 의존성 삭제·재설치·저장소 재복제를 하지 않는다.
- 관련 변경을 한 번에 적용하고 production build는 기본 1회, 실패 시 최대 2회까지만 시도한다.
- 같은 브라우저·배포 작업의 동일 재시도는 1회로 제한한다.
- 수정한 섹션만 선택적으로 검사하고 전체 페이지 문서를 다시 출력하지 않는다.
- GitHub 커밋·날짜별 로그 갱신·배포·배포 상태 확인은 각각 한 번만 수행한다.

콘텐츠 범위 제한:

- 평균 최저기온과 열대야 안내는 공식 출처 1개로 간단히 표시한다.
- 야간 콘텐츠는 이자카야, 슈퍼마켓, 중앙상점가, 선포트 야경 중심으로 제한한다.
- 새 이미지는 최대 4장, 이미지당 약 250KB 이하를 목표로 한다.
- 야돈 스탬프는 기존 시내 일정에 연결되는 공식 지점 2~4곳만 사용한다.
- 공통 일정 사진과 쇼도시마·나오시마·구라시키 Plan C 사진만 정리하며 기존 자산을 우선 재사용한다.
- 쇼도시마·나오시마 페리 시간은 이미 확인한 값을 재사용하고 다시 조사하지 않는다.
- 정상 작동 중인 다른 일정, 쿠폰북, Plan B, 여행 비용과 고베 Plan C는 수정하지 않는다.

2. production build 1회
