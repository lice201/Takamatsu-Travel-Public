# 2026-08-28 여행기 웹 방향 결정

- 3박 4일 다카마쓰 여행 기록은 동적 앱보다 정적 웹페이지로 구현하기로 방향을 정함.
- 핵심 구성은 사진 + 지도 + Day별 스크롤형 여행기.
- 초기 구현은 정적 HTML/CSS/JS + 지도 라이브러리(Leaflet 또는 Mapbox GL JS 중 단순한 쪽) + GitHub Pages 배포를 우선 고려.
- 백엔드, 로그인, DB, 실시간 데이터, 복잡한 EXIF 자동 분석은 1차 버전에서 제외.
- Codex는 초기 레이아웃/지도/반응형 구현에 주로 사용하고, 이후 사진/캡션 추가는 데이터 수정 위주로 단순화하는 구조가 적합.
- 목표는 Polarsteps의 여행 동선 표현과 scrollytelling 계열의 사진 중심 서술 방식을 결합한 가벼운 정적 여행 기록 페이지.
