# 2026-08-28 여행기록 웹페이지 구상 로그

## 요청
3박 4일 다카마쓰 여행 기록을 사진과 지도를 적극 활용한 웹페이지 형태로 구성하고 싶으며, 참고할 만한 사례와 방향을 검토.

## 검토한 레퍼런스
- Polarsteps: 지도 위 여행 경로 + 장소별 사진/메모 + 여행 전체 타임라인 방식.
- TravelMap: 지도를 홈페이지 중심에 두고 경로/교통수단/장소별 사진·글을 결합하는 여행 블로그 방식.
- FindPenguins: 이동 경로, 사진, 여행 통계 등을 한 여행 기록으로 결합.
- Mapbox Interactive Storytelling: 스크롤 위치에 따라 지도가 해당 장소로 이동하는 scrollytelling 방식.

## 현재 추천 방향
기존 여행계획 페이지와 별개로 `3박4일 여행기`를 하나의 스크롤 스토리로 제작.

구조 예시:
1. Cover — 대표 사진 + TAKAMATSU / 3 NIGHTS 4 DAYS + 날짜
2. Overview — 전체 여행 경로 지도 + 방문 장소 핀 + 간단 통계
3. Day 1~4 — 날짜별 세로 스크롤 타임라인
   - 왼쪽 또는 배경: 지도
   - 오른쪽: 실제 사진, 시간, 장소명, 짧은 코멘트
   - 스크롤하면 지도 카메라가 다음 방문지로 이동
4. 하루 종료 — 해당 날짜 이동 경로와 베스트 사진 모음
5. Epilogue — 전체 사진 갤러리, 먹은 음식, 이동거리/교통, 기억에 남은 장소 등 여행 결산

## 디자인 원칙
- 관광 안내 페이지보다는 개인 여행 사진집/저널 느낌
- 설명문을 길게 쓰기보다 사진 비중을 크게 유지
- 실제 이동 순서가 자연스럽게 보이도록 지도와 타임라인 동기화
- 모바일에서도 사진과 지도가 보기 좋도록 반응형 설계
