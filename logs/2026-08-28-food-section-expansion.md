# 2026-08-28 여행기 식당 섹션 확장

- 여행기 각 DAY에서 실제 방문 식당을 일반 stop에 묻지 않고 별도 음식/식당 영역으로 부각하기로 함.
- 식당 영역은 음식 사진, 식당명, 메뉴명, 식사 시각(알면), 1~2줄 후기 입력이 가능하도록 설계.
- 한 식당당 음식 사진은 2~5장 정도를 기본으로 허용하고, 필요하면 최대 6장까지 자연스럽게 렌더링 가능하게 구성.
- 기존 여행지 사진 갤러리(장소당 5~10장)와 식당 사진 영역은 목적을 구분해 별도 스타일을 사용.
- DAY 3 마루가메의 호네츠키도리 식사, DAY 4 유메타운의 스시로 점심 등은 독립 Food Stop 또는 Meal Section으로 표현하는 방향.
- 후기 문구는 사용자가 나중에 1~2줄로 직접 채울 수 있도록 데이터 필드로 분리하고, Codex가 임의의 감상평을 작성하지 않도록 함.
- 추천 데이터 구조: meal/foodStop 객체에 restaurantName, time, menu, note/review, photos를 분리.
- 전체 여행기 디자인 언어는 유지하되 FOOD / EAT 같은 작은 라벨, 음식 사진 중심 배치, 식당명 타이포그래피로 시각적 구분을 강화.
