# 2026-08-28 수동 Google Timeline형 여행동선 복원 구상

- 실제 여행 일정이 기존 계획과 달라졌음을 반영하기로 함.
- 실제 요약:
  - 2일차: 쇼도시마 탐방
  - 3일차: 고토히라 + 마루가메 + 붓쇼잔 온천
- Google Timeline 기록은 비활성화되어 원본 위치이력 데이터가 없음.
- 대안으로 사용자가 실제 방문 장소를 순서대로 Google Maps 링크(또는 정확한 장소명)로 제공하면 수동으로 위치 좌표와 이동 순서를 복원하는 방식이 적합함.
- 시간 정보는 정확한 기억, 사진 촬영시간(EXIF), 영수증/교통권/카드 결제시간 등으로 보완 가능.
- 최종 UI는 Google Timeline을 모사한 Day별 세로 타임라인 + 지도 경로 + 각 장소 사진/메모 조합을 우선 고려.
- 실제 이동수단은 사용자가 기억나는 범위에서 버스/페리/JR/고토덴/도보 등을 입력하고, 불확실한 구간은 '추정'으로 명시하는 것이 좋음.
- 다음 단계: 사용자가 Day별 실제 방문 장소를 이동 순서대로 Google Maps 링크로 전달하면 좌표/동선 데이터 구조를 먼저 작성한 뒤 Codex 수정 프롬프트를 생성.
