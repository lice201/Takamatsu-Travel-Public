# GitHub Pages 공개 URL 방향

- 사용자는 Codespaces의 임시 `app.github.dev` 프리뷰가 아니라 기존 `https://lice201.github.io/takamatsu-summer-2026/` 같은 GitHub Pages 고정 공개 URL을 원함.
- Takamatsu-Travel 저장소도 GitHub Pages 방식으로 배포해 항상 접근 가능한 URL을 만들 예정.
- 예상 URL 형태: `https://lice201.github.io/Takamatsu-Travel/`
- `/travel-log`를 별도 하위 경로로 둘지, 여행기를 루트 공개 페이지로 둘지는 배포 설정 시 결정.
- ChatGPT Sites는 이번 여행기 공개 경로로 사용하지 않는 방향.
