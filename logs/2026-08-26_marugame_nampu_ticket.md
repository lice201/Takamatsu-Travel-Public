# 2026-08-26 Marugame 이동 — 난푸 18호 승차권 확인

- 사용자 경로: 고토히라 15:47 → 마루가메 16:02, 특급 난푸 18호(오카야마행)
- 확인 사항: 지정석은 필수가 아님. 자유석 이용 가능.
- 단, 교통계 IC카드(ICOCA/Suica 등) 터치만으로 특급열차를 이용할 수는 없음.
- 고토히라→마루가메는 JR시코쿠 ICOCA 이용 가능 구간이므로 기본운임은 IC카드로 처리 가능.
- 난푸를 이용하려면 별도의 자유석 특급권 또는 지정석 특급권이 필요함.
- 즉, `IC카드 + 자유석 특급권` 조합으로 승차 가능하며 지정석을 반드시 살 필요는 없음.

Sources checked: JR Shikoku official ICOCA FAQ / Limited Express fare guide (2026-08-26).
