# Codex reasoning effort guidance — static travel diary

- Task: build a static 3-night/4-day Takamatsu travel diary website using photos and maps.
- Recommended default reasoning effort: **Medium**.
- Why: the task needs some structure/layout/map-data planning, but no difficult algorithms or large-scale architecture.
- Use **Low** for small edits after the initial build (text changes, photo swaps, spacing, CSS tweaks).
- Use **High** selectively for first-pass architecture, tricky map/scroll interactions, debugging layout issues across desktop/mobile, or when Codex must inspect an unfamiliar repository and make coordinated changes.
- **xhigh/max** is unnecessary for this project unless a genuinely difficult bug appears; it usually adds latency/tokens without proportional benefit for a simple static site.
- Practical workflow: initial scaffold at Medium, most iterative edits at Low/Medium, escalate individual hard debugging tasks to High.
